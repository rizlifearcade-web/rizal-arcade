# Contributing to Rizal Arcade

Thank you for helping build the classroom arcade. Protecting historical accuracy and the working production site is part of every contribution.

## Before coding

1. Ask for one assigned game or issue.
2. Create a branch from the latest `main`, such as `game/global-sojourn`.
3. Read `app/games/README.md` and the README inside your assigned folder.

## Pull-request requirements

- Keep the change inside the assigned game folder whenever possible.
- Explain the mechanic and exact Rizal-course topic.
- List historical sources and visual/audio licenses.
- Include screenshots at desktop and tablet sizes.
- Run the lint, build, and test commands.
- Never include secrets or modify production settings.

Only reviewed pull requests may enter `main`. A Vercel preview is for testing; it is not permission to merge.
